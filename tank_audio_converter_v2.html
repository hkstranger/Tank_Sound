        規格同注意事項
        • ESP32 只接受 WAV / PCM / 單聲道 / 16-bit / 22050 Hz，檔案要細過 1,500,000 bytes (約 34 秒)；格式唔啱會被拒絕，舊檔會保留。
        • RAM 快取：短音效會按 機槍 → 炮塔 → 升降 → 受擊 → 主炮 → 點火 → 熄匙 次序載入 RAM，合共上限 96 KB (約 2.2 秒)；放唔入嘅會由 flash 串流，可以正常播放。引擎檔一直由 flash 串流。
        • 更換音效：上載時新檔先寫入暫存，成功後先刪舊檔，所以空位要夠 「新檔大小 + 16 KB」。
        • 引擎循環：油門會令播放速度喺 0.65× 至 1.9× 之間變化，建議用中等轉速、音量穩定嘅錄音；頭尾要接得順。
        • 重取樣用 Kaiser 窗 sinc 濾波：9 kHz 以下幾乎冇影響 (≤ 0.03 dB)，10 kHz 約 −1.7 dB，12 kHz 以上被濾走 (−42 dB 或更多)，避免混疊假聲。22050 Hz 取樣率本身只可以表達 11 kHz 以下嘅聲音。
        • 自動保存：音效包會自動保存喺呢部瀏覽器 (IndexedDB)，重新整理都仲喺度；清除瀏覽資料、私隱模式或者換瀏覽器就會冇，所以完成後仍然請下載 ZIP 做備份。
        • 批量轉換：一次揀多個檔，按檔名關鍵字配對 (機槍 → 炮塔 → 升降 → 引擎 → 點火 → 熄匙 → 受擊 → 主炮 次序判斷；檔名剛好係 engine、fire 等音效位名稱會優先)。配唔到或者重複嘅會等你手動揀音效位。批量一律用該音效位預設 (自動去頭尾靜音、標準化 −1 dBFS)。
        • 本工具冇聲卡試聽功能以外嘅連線；最終請以坦克網頁「音效」分頁顯示 OK 為準。
